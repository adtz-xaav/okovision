# Security Policy

## Supported versions

Okovision is a small, actively developed project. Only the latest tagged release
(see [`CHANGELOG.md`](CHANGELOG.md)) is supported with security fixes — please
update before reporting an issue if you're running an older version.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities —
this project stores an encrypted boiler password and can issue live control
commands to physical heating hardware, so a public report could put running
instances at risk before a fix ships.

Instead, report privately using
[GitHub Security Advisories](https://github.com/adtz-xaav/okovision/security/advisories/new)
for this repository. If that isn't accessible, reach the maintainer via
[SAS Additiz](https://additiz.com) with a description of the issue and steps
to reproduce.

## Response time

This is a solo-maintained, best-effort project — there's no SLA, but reports
are taken seriously and will get a reply as soon as reasonably possible.
